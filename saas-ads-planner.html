Scaling Rules
✅ 20% SCALE-UP RULE
Actual CPA < Target by >10%
AND 7-day conversions ≥ learning threshold
AND NOT in learning phase
→ Increase budget by max 20%
→ Wait 3–5 days before next increase
❌ 3× KILL RULE
Spend > 3× target CPA ($450)
AND conversions = 0
→ Pause immediately
→ Review: creative, targeting, landing page, tracking
→ Don't restart without changes
